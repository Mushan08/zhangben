# 记账本

一个完全离线的记账应用。账目只存在你自己的设备上 —— 不联网、不上传、没有账号、没有广告。

**在线使用：** https://mushan08.github.io/zhangben/

> 本仓库是**网页版**的发布副本，供 iPhone 使用（iOS 无法侧载安装包，只能走网页加到主屏幕这条路）。
> 安卓版是独立的 APK，不在本仓库里。

## 在 iPhone 上安装

1. 用 **Safari** 打开上面的网址
2. 等页面完全加载完，点屏幕底部的**分享**按钮
3. 在列表里往下滑，找到 **「添加到主屏幕」**，点「添加」

装好后桌面上会多一个朱砂色的账页图标，点开**没有地址栏**，和普通应用一样。

**只有第一次需要联网**，之后完全离线 —— 飞行模式下也能记账。

> ⚠️ 微信、QQ、Chrome 的内置浏览器**没有**「添加到主屏幕」这个选项，必须用 Safari 打开。

## 功能

- **记账** — 支出 / 收入 / 转账，自绘数字键盘，可选账户、日期与备注
- **明细** — 按日分组并带当日小结，抬头是本月的支出、日均、收支与结余
- **统计** — 分类占比环形图、分类排行、近六个月趋势；点任一分类可下钻看每一笔
- **账户** — 现金、储蓄卡、信用卡、电子钱包、投资，自动按流水推算余额与净资产
- **预算** — 月度预算与进度条，超支时转为朱砂色；每个账本各有一份
- **账本** — 多账本（日常 / 旅行 / 装修…），可切换
- **数据** — 导出 CSV、备份为 JSON、从备份恢复
- **外观** — 浅色 / 深色 / 跟随系统，四种货币符号

## 隐私

- 应用**不申请任何权限**，安卓版连网络权限都没有 —— 不是"承诺不联网"，是系统层面就禁止它联网
- 所有账目存在设备本地，卸载即删除
- 没有账号、没有云同步、没有统计代码

### 请定期备份

**iOS 会在存储紧张、或这个应用很久没打开时回收网页数据。** 对记账软件这是硬伤，所以：

- **别删桌面上那个图标** —— 那等于卸载，数据会一起没
- 记账本 → **设置** → **备份为 JSON** → 存进「文件」后再挪到 iCloud 云盘
- 每周一次，或者记了一批账之后顺手备一次

换手机或重装后：先装好 → 设置 → **从备份恢复** → 选之前那个 JSON 文件。

## 技术说明

纯静态前端：HTML / CSS / 原生 JavaScript，**零依赖、无构建步骤**。

- 用 Service Worker 做离线缓存，加到主屏幕后体验接近原生应用
- 金额一律以「分」为整数存储，避免浮点误差
- 字体只含拉丁字形，中文回落到系统字体
- 界面语言是账簿：分类图标串在一条垂直「账线」上，金额一律等宽对齐，列表末尾用一道双线收口给出本月合计
